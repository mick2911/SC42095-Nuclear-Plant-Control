# SC42095 Nuclear Plant Control (Assignment 15-26)

Group project repository for SC42095 Digital Control (2026/2027).

## Structure
- `docs/` — Assignment description (`15-26.pdf`) and course manual.
- `matlab/` — MATLAB scripts, helper functions, and saved workspace data:
  - `q1_discretization.m` — Question 1: Continuous-time state-space model and discretization
  - `q2_4_pole_placement.m` — Questions 2–4: Discrete-time pole-placement design (nominal, input limit, input delay)
  - `q5_observer.m` — Question 5: Discrete-time observer design and integral action
  - `q6_8_lq_design.m` — Questions 6–8: Discrete-time LQ optimal control (nominal, input limit, input delay)
  - `q9_steady_state_error.m` — Question 9: Steady-state error elimination
- `report/` — Official Brightspace LaTeX report template (`main.tex`, `arxiv.sty`, `references.bib`) and exported `figures/`.
